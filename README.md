# Kairos

Kairos est un copilote d'investissement spécialisé dans les montres vintage.

Notre mission est de permettre à un investisseur de prendre de meilleures décisions grâce à l'analyse de marché, l'historique des ventes et un moteur de décision propriétaire.

Le logiciel répond à une question simple :

> Dois-je acheter cette montre ?
