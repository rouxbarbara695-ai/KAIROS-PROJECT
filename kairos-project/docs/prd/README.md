# Product Requirement Documents

Les PRD détaillés seront ajoutés avant chaque bloc de développement. Ils devront
contenir au minimum :

- problème utilisateur ;
- périmètre et non-périmètre ;
- parcours ;
- règles métier ;
- données nécessaires ;
- états d’erreur ;
- critères d’acceptation ;
- indicateurs de succès.

Le [MVP](../product/mvp.md) et le
[Sprint 1](../delivery/sprint-01.md) constituent le cadrage actif.
