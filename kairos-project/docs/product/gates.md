# Portes d’éligibilité

Une opportunité n’est notée que si elle franchit les portes suivantes :

| Porte | Condition | Résultat en cas d’échec |
|---|---|---|
| G1 — Authenticité | Aucun risque majeur identifié | Abandon / expertise nécessaire |
| G2 — Identification | Référence suffisamment fiable | Analyse impossible |
| G3 — Données | Informations minimales disponibles | Données à compléter |
| G4 — Marché | Comparables suffisants et pertinents | Estimation non fiable |
| G5 — Risque vendeur | Risque compatible avec la stratégie | Abandon ou contrôle renforcé |

Une porte d’éligibilité ne doit jamais être compensée par une marge élevée.
